# Settings (tvOS tab)

Mode: Operate. Audience: anyone who sideloads FooTube, plus their household, on the couch with the Siri Remote. Task: decide what happens with each SponsorBlock category, clear History or Watch Later, see the version, when this install expires, and credits. Infrequent use; must be readable from 3 m.

Constraints: binding native tvOS (PRODUCT.md). No new hosts, no account. Settings exist only for behavior the app has.

## Direction contract

THESIS: the Apple TV Settings app, mimicked exactly (owner's reference screenshot of Settings → Allgemein): centred grey page title, one fixed picture left, grouped rows right. Refuses a bespoke card grid, a modal-per-setting, or a changing symbol panel.

OWN-WORLD: grouped List rows, each on its own grey platter with the system focus lift; small uppercase section headers; values trailing in secondary text, chevrons only on rows that open a page. System type and appearance. The only colour is the app icon artwork (`AppArtwork`, generated by scripts/make-icon.swift). Clearing rows are plain rows; red appears only in the confirmation's destructive button.

STORY: the viewer moves down the list and the short text under the artwork says what the focused row means (SponsorBlock's category definitions, what clearing removes, when the install stops launching), so nothing needs a help page.

FIRST VIEWPORT: title "Settings" centred under the tab bar; artwork 520 pt wide, vertically centred in a 620 pt left column with the description below it at a fixed height; list right, SponsorBlock section first, each category with its current behavior as trailing value. The list scrolls below the title, never under it.

FORM: Apple TV Settings (title, picture + grouped list); a category opens a page titled with its name: three option rows with a checkmark on the current one.

SIGNATURE: the description under the artwork follows focus with a 200 ms crossfade, including on the option page, where it adds what the focused option does. The artwork never moves.

seed: none (form pinned by the native-tvOS brand commitment; no concept roll)
